ReadAnki プライバシーポリシー

最終更新日: 2026年10月7日（バージョン 3.2.1 Firefox版 対応）
正本: https://sshtorr-rgb.github.io/ReadAnki/privacy.html（他の掲載先と内容が異なる場合は正本が優先します）

1. 概要

ReadAnki（以下「本拡張機能」）は、ウェブページ上の英文やスクリーンショット内の英文をAIで文法解説し、★を付けた単語を穴埋めテストで復習できるブラウザ拡張機能です。Firefox版はAnkiとの連携機能を持たず、Anki関連の通信は行いません。開発者は独自のサーバーを持たず、利用者のデータを受け取ることも、収集・保存することもありません。

2. 扱うデータ

データ扱う場面送信先・保存先
選択した英文（最大500文字）と、それを含む1文（最大500文字）利用者が「解説」ボタン・右クリックメニューを使ったとき利用者が選んだLLMプロバイダへ送信。利用者が解析画面で「履歴に保存」を押した場合のみ、解析結果とともに端末内の履歴に保存
貼り付けたスクリーンショット画像利用者が「画像貼り付け」を使ったとき利用者が選んだLLMプロバイダへ送信。画像は保存しません（「履歴に保存」を押した場合のみ、抽出された英文と解析結果を履歴に保存）
単語・文（解析結果の一部）利用者が単語定義・言い換え・例文生成を使ったとき利用者が選んだLLMプロバイダへ送信
単語帳の語と、その語を含む1文、記事のURL（# 以降と追跡用パラメータを除く）とタイトル利用者が「＋単語」を押したとき端末内の拡張機能ストレージにのみ保存（この時点では送信しません）
単語帳の語と、その語を含む1文利用者が単語帳画面で「AIで意味を付ける」を押したとき利用者が選んだLLMプロバイダへ送信（URL・タイトルは送りません）
APIキー設定画面で入力したとき対応するLLMプロバイダへの認証にのみ使用。既定ではブラウザ終了までの一時保存。利用者が選んだ場合のみ拡張機能ストレージに保存（暗号化はされません）
設定・同意状態・直近のエラー内容常時端末内の拡張機能ストレージのみ。エラー内容はAPIキーを伏せ字にし、利用者が「診断情報をコピー」を押したときだけクリップボードへ出力

本拡張機能は、閲覧履歴・ページ全体の内容・個人を特定する情報を収集しません。記事のURLとタイトルは、利用者が「＋単語」を押した記事についてだけ端末内の単語帳に保存し、外部へは送りません。ページへのアクセスは、利用者が有効化したタブに限られます（「6. 権限の用途」参照）。

3. 共有先（第三者）

解析対象は、利用者が設定画面で選んだ次のいずれか1つへ、利用者の端末から直接（HTTPS、またはローカルの場合は端末内通信で）送信されます。

  • Google Gemini API（Google LLC）— Gemini API 利用規約、Google プライバシーポリシー
  • OpenAI API（OpenAI）— OpenAI プライバシーポリシー
  • 利用者が自分で指定したOllama、またはOpenAI互換サーバー（ローカル、または利用者が許可したHTTPSのサーバー）

送信後のデータの取り扱い（保存期間、サービス改善への利用など）には、各プロバイダの規約とプライバシーポリシーが適用されます。特に無料枠では、送信内容がプロバイダの製品改善に利用される場合があります。機密情報や個人情報を含む文章・画像は解析しないでください。

このほか、利用者が操作したときに限り次の処理が行われます。

  • 発音再生: ブラウザの音声合成機能を使います。ブラウザや選ばれた音声によっては、ブラウザ提供者のサービスで処理される場合があります。
  • 外部辞書リンク: 設定で選んだ場合、単語をクリックするとCambridge Dictionaryのページがその単語をURLに含めて開きます。

開発者はこれら以外の第三者へデータを提供・販売せず、広告、行動追跡、信用評価に利用しません。

4. 端末内の保存と削除

プライベートウィンドウで解析した結果は、履歴にも単語帳にも保存しません（「履歴に保存」ボタン・「＋単語」は使えません）。

解析結果は自動では保存されません。利用者が解析画面で「履歴に保存」を押したときだけ、解析履歴（対象英文、1文の文脈、解析結果、使用プロバイダ名、日時、未知語の印と穴埋めテストの復習予定）を端末の拡張機能ストレージに保存します。最大500件で、それを超えると古いものから削除されます。履歴画面から個別または一括で削除できます。単語帳は記事ごとに保存し（1記事200語・300記事まで。超えると古い記事から削除）、単語帳画面から語ごと・記事ごとに削除できます。本拡張機能をアンインストールすると、端末内のすべてのデータが削除されます。

5. 同意

インストール直後に設定画面を表示し、上記のデータ処理を説明します。利用者が同意するまで、LLMプロバイダへの送信は一切行いません。

6. 権限の用途

権限用途
activeTab, scripting利用者がポップアップの「このページで有効化」、右クリックメニュー（パソコンのみ）を使ったタブにだけ、解析用の表示を追加するため。全サイトへの常時アクセスは要求しません。
contextMenus選択した英文を右クリックから解析するため（パソコンのみ。Android では使用しません）
storage設定、同意状態、解析履歴、単語帳を端末内に保存するため
generativelanguage.googleapis.com, api.openai.com利用者が選んだLLMプロバイダへ解析対象を送信するため
localhost, 127.0.0.1端末上のOllama・ローカルLLMと通信するため
任意のHTTPSサイト（オプション、https://*/*）インストール時には要求しません。利用者が外部のOpenAI互換サーバーを設定したときに限り、そのホストだけの許可を実行時に求めます。about:addons での権限の取り消しでいつでも解除できます。

7. ストアのポリシーへの準拠

Firefox版（Android を含む）は Mozilla の Add-on Policies に従い、送信するデータの種類（ウェブサイトの内容）を拡張機能の設定（manifest）で申告し、インストール時に Firefox の同意画面でも表示します。

本拡張機能によるユーザーデータの利用は、Limited Use（使用制限）要件を含む Chrome Web Store User Data Policy に準拠します。ユーザーデータは上記の単一目的（英文の文法解説と、その復習）の提供にのみ使用し、人がデータを閲覧することはありません。

8. 変更

本ポリシーを変更する場合は、このページの最終更新日を更新し、データの取り扱いが変わるときは拡張機能内でも案内します。
