ReadAnki プライバシーポリシー

最終更新日: 2026年9月29日（バージョン 3.0.5 対応）
正本: https://sshtorr-rgb.github.io/ReadAnki-OSS/privacy.html（他の掲載先と内容が異なる場合は正本が優先します）

1. 概要

ReadAnki（以下「本拡張機能」）は、ウェブページ上の英文やスクリーンショット内の英文をAIで文法解説し、Ankiの学習カードにするChrome拡張機能です。開発者は独自のサーバーを持たず、利用者のデータを受け取ることも、収集・保存することもありません。

2. 扱うデータ

データ扱う場面送信先・保存先
選択した英文（最大500文字）と、それを含む1文（最大500文字）利用者が「解説」ボタン・右クリックメニューを使ったとき利用者が選んだLLMプロバイダへ送信。利用者が解析画面で「履歴に保存」を押した場合のみ、解析結果とともに端末内の履歴に保存
貼り付けたスクリーンショット画像利用者が「画像貼り付け」を使ったとき利用者が選んだLLMプロバイダへ送信。画像は保存しません（「履歴に保存」を押した場合のみ、抽出された英文と解析結果を履歴に保存）
解析結果から作ったAnkiカードの内容利用者が「Anki追加」を押したとき利用者の端末上のAnkiConnect（127.0.0.1 など）
単語・文（解析結果の一部）利用者が単語定義・言い換え・例文生成を使ったとき利用者が選んだLLMプロバイダへ送信
APIキー設定画面で入力したとき対応するLLMプロバイダへの認証にのみ使用。既定ではブラウザ終了までの一時保存。利用者が選んだ場合のみ拡張機能ストレージに保存（暗号化はされません）
設定・同意状態・直近のエラー内容常時端末内の拡張機能ストレージのみ。エラー内容はAPIキーを伏せ字にし、利用者が「診断情報をコピー」を押したときだけクリップボードへ出力

本拡張機能は、閲覧履歴・閲覧中のURL・ページ全体の内容・個人を特定する情報を収集しません。ページへのアクセスは、利用者が有効化したタブと、利用者が「常に有効にするサイト」に登録したサイトに限られます（「6. 権限の用途」参照）。登録したサイトでも、送信が行われるのは利用者が解析を実行したときだけです。

3. 共有先（第三者）

解析対象は、利用者が設定画面で選んだ次のいずれか1つへ、利用者の端末から直接（HTTPS、またはローカルの場合は端末内通信で）送信されます。

  • Google Gemini API（Google LLC）— Gemini API 利用規約、Google プライバシーポリシー
  • OpenAI API（OpenAI）— OpenAI プライバシーポリシー
  • 利用者が自分で指定したOllama、またはOpenAI互換サーバー（ローカル、または利用者が許可したHTTPSのサーバー）

送信後のデータの取り扱い（保存期間、サービス改善への利用など）には、各プロバイダの規約とプライバシーポリシーが適用されます。特に無料枠では、送信内容がプロバイダの製品改善に利用される場合があります。機密情報や個人情報を含む文章・画像は解析しないでください。

このほか、利用者が操作したときに限り次の処理が行われます。

  • 発音再生: ブラウザの音声合成機能を使います。ブラウザや選ばれた音声によっては、ブラウザ提供者のサービスで処理される場合があります。
  • 外部辞書リンク: 設定で選んだ場合、単語をクリックするとCambridge Dictionaryのページがその単語をURLに含めて開きます。

開発者はこれら以外の第三者へデータを提供・販売せず、広告、行動追跡、信用評価に利用しません。

4. 端末内の保存と削除

解析結果は自動では保存されません。利用者が解析画面で「履歴に保存」を押したときだけ、解析履歴（対象英文、1文の文脈、解析結果、使用プロバイダ名、日時、未知語の印）を端末の拡張機能ストレージに保存します。最大500件で、それを超えると古いものから削除されます。履歴画面から個別または一括で削除できます。本拡張機能をアンインストールすると、端末内のすべてのデータが削除されます。

5. 同意

インストール直後に設定画面を表示し、上記のデータ処理を説明します。利用者が同意するまで、LLMプロバイダへの送信は一切行いません。

6. 権限の用途

権限用途
activeTab, scripting利用者がポップアップの「このページで有効化」、右クリックメニュー、ショートカットを使ったタブにだけ、解析用の表示を追加するため。全サイトへの常時アクセスは要求しません。
contextMenus選択した英文を右クリックから解析するため
storage設定、同意状態、解析履歴を端末内に保存するため
generativelanguage.googleapis.com, api.openai.com利用者が選んだLLMプロバイダへ解析対象を送信するため
localhost, 127.0.0.1端末上のOllama、ローカルLLM、AnkiConnectと通信するため
任意のサイト（オプション、https://*/*・http://*/*）インストール時には要求しません。次の場合に限り、そのホストだけの許可を実行時に求めます: (1) 利用者が「常に有効にするサイト」に登録したとき（そのサイトで英文選択時の表示を常に出すため）、(2) 利用者が外部のOpenAI互換サーバーを設定したとき。登録の削除、または chrome://extensions での権限の取り消しでいつでも解除できます。

7. Chrome ウェブストアのユーザーデータポリシーへの準拠

本拡張機能によるユーザーデータの利用は、Limited Use（使用制限）要件を含む Chrome Web Store User Data Policy に準拠します。ユーザーデータは上記の単一目的（英文の文法解説とAnkiカード化）の提供にのみ使用し、人がデータを閲覧することはありません。

8. 変更

本ポリシーを変更する場合は、このページの最終更新日を更新し、データの取り扱いが変わるときは拡張機能内でも案内します。
