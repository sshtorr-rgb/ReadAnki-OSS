# ReadAnki Firefox版（パソコン・Android）

ニュース等のWeb英文読解中に、ReadAnkiを有効化したタブでテキストを選択すると「三点リーダー (⋯)」がポップアップし、
クリックすることでミニツールバーが展開。LLM（LM StudioなどのローカルLLM / Ollama / Gemini / OpenAI）による実践的文法構文解析と、★を付けた単語の穴埋めテストができます。Firefox版にAnki連携機能はありません。

## 1. 拡張機能のインストール手順 (Windows)

1. ダウンロードした `ReadAnki-Chrome-Extension.zip` を任意のフォルダに解凍します。
2. Google Chrome または Microsoft Edge を開きます。
3. アドレスバーに以下を入力して開きます:
   - Chromeの場合: `chrome://extensions`
   - Edgeの場合: `edge://extensions`
4. 画面右上（または左メニュー）の **「デベロッパーモード」** をONにします。
5. **「パッケージ化されていない拡張機能を読み込む」** (Load unpacked) ボタンをクリックします。
6. 先ほど解凍したフォルダを選択します。
7. これで拡張機能がブラウザに追加されます！

## 2. 設定の開き方

- **三点リーダーメニューから開く**: Webページ上で英文を選択し、展開したメニューの「⚙️ (設定)」をクリック
- **拡張機能アイコンから開く**: ブラウザ右上の拡張機能アイコンから「ReadAnki」をクリックし、「⚙️ 拡張機能の設定を開く」をクリック
- **拡張機能管理から開く**: `chrome://extensions` の ReadAnki の「詳細」→「拡張機能のオプション」をクリック

## 3. OpenAI互換 (ローカルLLM: LM Studio / vLLM / LocalAI) の利用方法

**完全ローカル・無料・オフライン** で最先端モデル（Llama 3.2, Qwen 2.5, Gemma 2等）を実行できます。

### LM Studio でのセットアップ (おすすめ)
1. Windowsマシンで **LM Studio** を起動します。
2. お好みのモデル（例: `Llama-3.2-3B-Instruct` や `Qwen2.5-7B-Instruct`）をロードします。
3. 画面左側の **「Developer (ローカルサーバー)」** アイコンをクリックします。
4. ポートを `1234` に設定し、**「Start Server」** をクリックします。
5. ReadAnkiの設定（または三点リーダー内の⚙️）を開き:
   - プロバイダ: **「OpenAI互換 (ローカルLLM)」** を選択
   - URL: `http://localhost:1234/v1`
   - モデル名: `local-model` (またはロード中のモデルID)
6. これでWebニュースや英文記事上で、ローカルLLMによる高速な構文解析が利用できます！

## 4. Ollama (ローカルLLM) を利用する場合の注意点

ブラウザからローカルのOllama (`http://localhost:11434`) にリクエストを送る場合、CORS（オリジン間リソース共有）許可が必要です。

Windowsのコマンドプロンプトで以下を実行してOllamaを起動してください:

```cmd
set OLLAMA_ORIGINS=chrome-extension://*
ollama serve
```

`OLLAMA_ORIGINS=*` は任意のウェブサイトからローカルLLMを呼び出せる設定になるため使用しないでください。

モデルの事前ダウンロード（推奨）:
```cmd
ollama pull llama3.2
```

## 5. 使い方

1. 英語のニュース記事（BBC, CNN, Reuters, The New York Times等）を開きます。
2. そのタブでReadAnkiを有効化します。次のどれでも有効化できます:
   - ブラウザ右上のReadAnkiアイコン →「✨ このページで有効化」
   - 英文を選択して右クリック →「ReadAnki: 文法解説」（パソコンのみ。そのまま解説カードが開きます）
3. 気になる単語や文（500文字まで）を選択すると、直上に **三点リーダーボタン (⋯ ReadAnki)** が表示されます。
   ReadAnkiは全サイトへの常時アクセスを要求しません。有効化はタブごとで、ページを移動したら再度有効化してください。
   よく読むサイトは、ポップアップの「📌 このサイトを常に有効にする」か、設定画面の「常に有効にするサイト」で登録すると、毎回の有効化が不要になります（登録時にそのサイトだけのアクセス許可を求めます）。
4. **⋯** をクリックするとメニューが展開:
   - **[🪄 解説]**: 解説カードを開きます
   - **[🔊]**: ネイティブ発音の読み上げ
   - **[⚙️]**: 設定画面の起動
5. 解析結果は自動では保存されません。あとで見返したい場合や未知語（★）を登録したい場合は「💾 履歴に保存」を押してください。
6. 履歴画面の「🧠 未知語テスト」では、★を付けた語をすべて穴にした英文と、その和訳が出ます。「答えを見る」を押すと、穴に入る単語と意味が表示されます。

## 6. プライバシー

解析を実行したときだけ、選択した英文（とそれを含む1文）または貼り付け画像を、設定で選んだLLMプロバイダへ直接送信します。開発者のサーバーは経由しません。詳細は [プライバシーポリシー](https://sshtorr-rgb.github.io/ReadAnki/privacy.html) を参照してください。

## 7. Firefox版（Android を含む）について

このブランチ（`firefox`）は Firefox 用です。パソコン版の Chrome 拡張は `main` ブランチで管理しています。

- 対応バージョン: Firefox 140 以降（Android は 142 以降）
- 試しに入れる方法（パソコン）: `about:debugging` →「この Firefox」→「一時的なアドオンを読み込む」で `extension/manifest.json` を選ぶ
- 試しに入れる方法（Android）: スマホの「USBデバッグ」を有効にしてパソコンとUSBでつなぎ、パソコンで `npx web-ext run -s extension --target=firefox-android --android-device=<端末ID>` を実行する（端末IDは `adb devices` で確認）。Mozilla 公式の手順で、アプリ側は Firefox for Android（Nightly 推奨）を使う
- AMO に「非公開（unlisted）」で提出して署名を受けた `.xpi` なら、Firefox for Android Nightly の「ファイルからアドオンをインストール」でも入れられる
- Android での使い方: 英文を長押しで選択すると、選択範囲の下に ⋯ が表示されます。右クリックメニューとショートカットはありません
- Anki連携はありません（Android の AnkiDroid には外部からカードを追加できないため、Firefox版ではパソコン・Android とも外しています）
- プライベートウィンドウで解析した結果は、履歴に保存しません
